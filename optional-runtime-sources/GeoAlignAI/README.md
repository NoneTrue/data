# GeoAlignAI redistributable source subset

This archive contains LoFTR and YACS source files used in the local optional GeoAlignAI development folder. Both projects are licensed under Apache License 2.0; their license files are included next to the sources.

SuperGlue, SuperPoint and their model weights are intentionally excluded because the owner's license restricts redistribution. This subset alone is not a working ChangeVision inference backend. See `OPTIONAL_RUNTIME.md` in the ChangeVision repository for the opt-in owner-source downloader and installation details.
